# 首轮交付记录

版本：0.1.0。更新：2026-09-08。

本轮交付了可运行的 **浏览器导入 → 源码/二进制结构解析 → 函数、代码与位置 → 持久化任务/事件/产物 → JSON、HTML、Markdown 报告**。它完成程序理解的基础链路，完整课程功能仍按 R01—R15 继续实现。

## 已实现

| 模块 | 实际行为 |
| --- | --- |
| 工程与通信 | 五个 Rust crate、Svelte 5 / TypeScript 前端、单一 Protobuf 契约、官方 Rust/TS Connect 生成接口、SQLite 迁移、固定依赖 |
| 导入与快照 | ZIP、浏览器文件夹、指定版本 HTTPS Git、PE/ELF；文件/目录限制、路径和符号链接检查、排除理由、版本及哈希归档 |
| 源码理解 | Tree-sitter 解析 Python、Go、C、C++；模块与函数、精确 UTF-8 字节和行范围、语法分支、带推断/未知标记的调用关系 |
| 二进制理解 | 真实 Ghidra Headless；PE x86/x64、ELF x86_64；函数、伪代码、入口/RVA、调用点、基本块、P-code 和字符串引用；反编译失败、截断和原始日志保留 |
| 任务与执行器 | 能力检查/刷新、队列、工作租约与心跳、幂等请求、事件游标重连、显式取消、失效结果拒绝；未知进程状态不会自动重跑 |
| 工具生命周期 | 环境变量白名单、进程组 / Windows Job Object、超时、取消、输出限量、回收确认；Windows 子进程先以挂起状态加入 Job，再恢复运行 |
| 界面与报告 | 项目/快照、任务历史、只读 Monaco、局部调用图、覆盖缺口、事件及产物下载、执行环境；报告引用真实目标和证据哈希 |
| 模型连接 | DeepSeek 官方 deepseek-v4-flash；后台 JSON 响应检查、真实 token 记录、幂等请求、服务重启中断状态、私有密钥文件与脱敏错误；尚未进行漏洞审计 |
| 本地运行 | 安装、构建、检查、代码生成、启动/停止和打包脚本；管理进程与本地分析数据分别保存 |

报告中漏洞审计、独立复核、模糊测试与利用均为 `NOT_RUN`。无漏洞列表或零检出率填充，不将解析完成解释为目标安全。源码控制流为语法级线索，伪代码为函数级映射，不宣称完整语义 CFG 或逐行机器指令映射。
