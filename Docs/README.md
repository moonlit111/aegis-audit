本项目选定课程设计第 1 题：**基于大模型智能体的软件漏洞挖掘系统设计与实现**。

项目采用“以需求驱动设计、用已有漏洞检验能力”的方向。系统面向未专项适配过的源码和二进制开展漏洞挖掘；公开历史漏洞提供评测依据。系统主体自行实现，可以充分借鉴开源设计与模块源码，并记录来源及改动。

**项目的设计、实现、调试、测试和技术文档由 Codex 承担。** 开发计划只保留依赖、执行顺序及完成标准，不制定日历排期或成员开发分配。课程规定的提交信息按真实情况整理。

已确定采用 **Rust + Axum/Tokio 核心后端、TypeScript + Svelte 前端、Connect RPC 通信、SQLite 存储**。Python/Java 保留用于必要的分析工具适配脚本。当前 0.2.0 在结构分析工作台上加入多智能体审计、独立复核、人工修订和 Linux 动态执行；具体能力和实际验证范围见[审计与动态验证交付记录](审计与动态验证交付记录.md)。

首版漏洞挖掘范围已确定为注入、路径遍历、认证/授权缺陷和内存越界，四类开发夹具的真实模型审计及动态缺陷/修复对照已通过。已对照课程 PDF 确认原文未限定漏洞类型；完整功能和三类软件各两种的正式测试要求仍按原文执行，开发夹具不计入六项正式软件。

执行环境为 Windows 主执行和最终验收，Mac 用于日常开发与平台调试。Windows 电脑由用户确认配置为 Windows 11 专业版、Intel Core i9-13900HX、32 GB 内存、500 GB 硬盘；Mac 经本地检查为 ARM、16 GB 内存。Windows 的具体系统构建号、虚拟化及工具状态尚待实际检查。

模型服务已确定使用 DeepSeek 官方 API，首版按此前偏好优先适配 deepseek-v4-flash。服务地址、模型标识和密钥引用通过配置提供，一个模型可承担多个独立上下文的智能体角色。用户不设 API 费用总额上限，后续 API 适配由 Codex 自主处理，不再作为访谈议题。已完成真实模型审计与修复对照，保留各角色任务、原始调用、格式纠正及实际用量。

当前实测包括 27 项 Rust 测试、真实模型的漏洞/修复对照、13 项动态回归和 5 项浏览器测试。安装方式见[安装与运行](安装与运行.md)，复用范围见[开源参考与依赖](开源参考与依赖.md)。Windows 实机与原生 PE 动态验证、自动保护处理、完整目标利用及开源系统对照仍待完成；Windows 的准备材料见[接力任务](Windows接力任务.md)，六项正式软件的候选及缺口见[正式样本筛选](正式样本筛选.md)。

R01—R15 对应课程要求，U01—U06 对应本次确定的项目约束。实现与测试按编号提供证据，开发中的阶段成果不减少最终验收范围。
