本项目选定课程设计第 1 题：**基于大模型智能体的软件漏洞挖掘系统设计与实现**。

项目采用“以需求驱动设计、用已有漏洞检验能力”的方向。系统面向未专项适配过的源码和二进制开展漏洞挖掘；公开历史漏洞提供评测依据。系统主体自行实现，可以充分借鉴开源设计与模块源码，并记录来源及改动。

**项目的设计、实现、调试、测试和技术文档由 Codex 承担。** 开发计划只保留依赖、执行顺序及完成标准，不制定日历排期或成员开发分配。课程规定的提交信息按真实情况整理。

已确定采用 **Rust + Axum/Tokio 核心后端、TypeScript + Svelte 前端、Connect RPC 通信、SQLite 存储**。Python/Java 保留用于必要的分析工具适配脚本。0.1.0 结构分析工作台已实现，兼容依赖已经锁定；完整能力和实际验证范围见[首轮交付记录](首轮交付记录.md)。

首版漏洞挖掘范围已确定为注入、路径遍历、认证/授权缺陷和内存越界。已对照课程 PDF 确认原文未限定漏洞类型；完整功能和三类软件各两种的正式测试要求仍按原文执行，相关能力均待实现与验证。

执行环境为 Windows 主执行和最终验收，Mac 用于日常开发与平台调试。Windows 电脑由用户确认配置为 Windows 11 专业版、Intel Core i9-13900HX、32 GB 内存、500 GB 硬盘；Mac 经本地检查为 ARM、16 GB 内存。Windows 的具体系统构建号、虚拟化及工具状态尚待实际检查。

模型服务已确定使用 DeepSeek 官方 API，首版按此前偏好优先适配 deepseek-v4-flash。服务地址、模型标识和密钥引用通过配置提供，一个模型可承担多个独立上下文的智能体角色。用户不设 API 费用总额上限，后续 API 适配由 Codex 自主处理，不再作为访谈议题。已使用 deepseek-v4-flash 完成真实 JSON 连接检查并保存用量；智能体审计尚未接入。

已完成浏览器导入、真实源码/Ghidra 结构解析、持久化任务及事件、代码与调用图、三种结构报告和行为测试。安装方式见[安装与运行](安装与运行.md)，复用范围见[开源参考与依赖](开源参考与依赖.md)。DeepSeek 官方连接检查已实测；多智能体漏洞审计、保护处理和实际漏洞利用尚未完成，Windows 目标主机尚未连接；六项正式软件的候选及缺口见[正式样本筛选](正式样本筛选.md)。

R01—R15 对应课程要求，U01—U06 对应本次确定的项目约束。实现与测试按编号提供证据，开发中的阶段成果不减少最终验收范围。
