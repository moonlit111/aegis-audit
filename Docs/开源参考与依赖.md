# 开源参考、复用与许可证

本轮核查日期：2026-09-08。参考官方文档和公开代码来实现通用模块；本项目业务控制、存储、证据状态和界面代码自行编写。依赖的准确版本以 `Cargo.lock`、`frontend/pnpm-lock.yaml` 和 `tools/versions.json` 为准。

| 项目 | 许可与本轮使用 | 对应实现 |
| --- | --- | --- |

| [Ghidra](https://github.com/NationalSecurityAgency/ghidra/tree/Ghidra_12.1.3_build) | Apache-2.0，发行包还含第三方组件许可；外部工具进程，通过官方 `DecompInterface`、`BasicBlockModel`、P-code 与引用 API 导出结果 | `tools/ghidra/ExportProgram.java`、`crates/executor/src/jobs.rs`；脚本自行实现，保留入口地址/RVA、失败、截断和工具版本 |

| [Svelte](https://github.com/sveltejs/svelte)、[fflate](https://github.com/101arrowz/fflate)、[Lucide](https://github.com/lucide-icons/lucide) | Svelte / fflate：MIT；Lucide 图标按其 ISC 及衍生图标许可（包内 license 文件） | 中文工作台、浏览器异步 ZIP 打包和图标；没有复制其他产品的业务页面 |
| Axum / Tokio / SQLx / object / zip 等 Rust 库 | 按各锁定包的 MIT、Apache-2.0 等声明；详见自动生成许可证清单 | HTTP、异步进程、SQLite、PE/ELF 元数据读取及 ZIP 处理；所有项目/任务/证据约束由本项目实现 |

SQLite 引擎随 Rust 依赖构建，不要求独立数据库服务。JDK、Git、Ghidra 作为外部工具安装，保留各自原有许可及第三方声明；应用运行包不重新分发这些大型工具。

## DeepAudit 的参考范围

核查对象是 [lintsinghua/DeepAudit](https://github.com/lintsinghua/DeepAudit)，核查提交 `324133fe60b540327d182fbb8c800aa65a613349`，默认开发分支为 `v3.0.0`，许可证 **AGPL-3.0**。本轮阅读了该版本 README 的工作流，以及以下实际源文件：

- [`backend/app/models/audit.py`](https://github.com/lintsinghua/DeepAudit/blob/324133fe60b540327d182fbb8c800aa65a613349/backend/app/models/audit.py)：审计任务和问题记录的关系、状态及位置字段。
- [`backend/app/services/agent/core/executor.py`](https://github.com/lintsinghua/DeepAudit/blob/324133fe60b540327d182fbb8c800aa65a613349/backend/app/services/agent/core/executor.py)：智能体执行任务、依赖、结果、错误和用量的组织方式。

参考用途是核对后续多智能体职责及审计数据的组织问题。本轮未复制或移植这些 AGPL 业务源码，未部署 DeepAudit、未运行共同漏洞测试集，也没有性能或检出效果的优劣结论。R13 的实际系统对照仍待后续完成。

本轮已实现的独立工作包括：源码与 PE/ELF 的统一结构对象、不可变快照、SQLite 状态/事件事务、执行器能力与租约、失效结果拒绝、显式取消与回收确认、文件访问范围、覆盖缺口展示，以及引用真实产物的三种报告。这些模块不依赖项目名称或 CVE 专用判断。

## 分发记录

```bash
python3 scripts/notices.py
python3 scripts/package.py
```

许可证收集脚本从已安装的 Cargo / pnpm 包读取上游许可元数据和许可文件，输出包名、版本、来源及原始声明。运行包包含 `THIRD-PARTY-NOTICES/` 和逐文件 SHA-256 清单。Rust 列表保守包含可选和构建依赖，不能把包数当成实际运行时加载数量。

公开 GitHub 仓库不自动等于给本项目选择了某个开源许可证；本轮没有替用户新增项目自身的授权条款。第三方组件继续受各自许可证约束。
