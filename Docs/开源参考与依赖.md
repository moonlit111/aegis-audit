动态镜像由 `tools/runtime/Dockerfile` 在本机构建，保留其安装包中的原始许可证；应用 ZIP 包含构建定义和适配脚本，不包含镜像。基础镜像及 UPX 下载固定摘要，系统包来自 Debian 仓库；每次实际运行记录镜像 ID，未将系统包重建描述为逐字节可复现。

## DeepAudit 的参考范围

核查对象是 [lintsinghua/DeepAudit](https://github.com/lintsinghua/DeepAudit)，核查提交 `324133fe60b540327d182fbb8c800aa65a613349`，默认开发分支为 `v3.0.0`，许可证 **AGPL-3.0**。本轮阅读了该版本 README 的工作流，以及以下实际源文件：

- [`backend/app/models/audit.py`](https://github.com/lintsinghua/DeepAudit/blob/324133fe60b540327d182fbb8c800aa65a613349/backend/app/models/audit.py)：审计任务和问题记录的关系、状态及位置字段。
- [`backend/app/services/agent/core/executor.py`](https://github.com/lintsinghua/DeepAudit/blob/324133fe60b540327d182fbb8c800aa65a613349/backend/app/services/agent/core/executor.py)：智能体执行任务、依赖、结果、错误和用量的组织方式。

参考用途是核对多智能体职责及审计数据的组织问题。本轮未复制或移植这些 AGPL 业务源码，未部署 DeepAudit、未运行共同漏洞测试集，也没有性能或检出效果的优劣结论。R13 的实际系统对照仍待后续完成。

## Claude Code Security Review 的参考范围

本轮阅读了 [anthropics/claude-code-security-review](https://github.com/anthropics/claude-code-security-review) 的固定提交 `0c6a49f1fa56a1d472575da86a94dbc1edb78eda`，许可证为 MIT。核查文件为 `claudecode/findings_filter.py`、`claudecode/prompts.py` 和 `LICENSE`，下载版本及原文保留在本地 `.data/references/claude-code-security-review/`。

借鉴内容是独立复核、检查真实攻击条件及减少推测性告警的工作流。AegisAudit 自行实现输入控制、操作可达性、防护缺口与额外前提的逐项证据判定，没有复制该项目的过滤器或提示词，也未沿用其基于语言的内存问题排除规则。当前仍审计所声明的四类缺陷；未知必要条件保留不确定状态，组件级依据与完整部署结论分别记录。尚未运行两个系统的共同样本对照。

本轮已实现的独立工作包括：源码与 PE/ELF 的统一结构对象、不可变快照、SQLite 状态/事件事务、执行器能力与租约、失效结果拒绝、显式取消与回收确认、文件访问范围、模型编排、代码引文校验、独立复核、人工修订、容器执行与复测、覆盖缺口展示，以及引用真实产物的三种报告。这些模块不依赖项目名称或 CVE 专用判断。

## 分发记录

```bash
python3 scripts/notices.py
python3 scripts/package.py
```

许可证收集脚本从已安装的 Cargo / pnpm 包读取上游许可元数据和许可文件，输出包名、版本、来源及原始声明。运行包包含 `THIRD-PARTY-NOTICES/` 和逐文件 SHA-256 清单。Rust 列表保守包含可选和构建依赖，不能把包数当成实际运行时加载数量。

公开 GitHub 仓库不自动等于给本项目选择了某个开源许可证；本轮没有替用户新增项目自身的授权条款。第三方组件继续受各自许可证约束。
