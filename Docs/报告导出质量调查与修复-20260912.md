# 报告导出质量调查与修复（2026-09-12）

报告质量差主要由内容拼装、字段缺失和打印结构共同造成。已检查前端导出入口、服务端冻结快照与保存流程、HTML/Markdown/JSON 渲染器，以及本机浏览器生成 PDF 的链路，并修复了能复现的问题。

真实历史样本中，llama-jinja 报告开头先列出 91 个程序单元，第 151 行才进入“发现与复核”。报告智能体的摘要、建议和限制已被保存，但没有整理成可直接阅读的摘要章节，而是被埋在原始 JSON 中。PDF 直接打印 HTML，因此继承了 HTML 的结构和内容问题。

| 已确认问题 | 影响 | 本次修复 |
| --- | --- | --- |
| 结果前堆放完整单元清单，缺少风险概览 | 读者难以快速判断发现数量、复核状态和覆盖范围 | 首页展示静态证实、待复核、待补证、已否决数量，以及严重程度、运行验证和单元完成率；完整单元清单移入附录 |
| HTML 与 Markdown 分别拼接内容 | Markdown 漏掉严重度依据；两种格式对利用证据的描述强度不同 | 共用一份章节和内容结构，再输出两种格式；PDF 继续使用同一 HTML |
| 多行原文通过普通文本转义并折叠换行 | 代码引文、缩进和多段说明难读 | 原文使用独立代码块；Markdown 动态选择长于原文中反引号串的围栏；普通多行说明保留换行 |
| 复核 assessments 和复核原始证据未展开 | 缺少输入控制、可达性、防护缺口的逐项依据 | 展示各项判定、理由、引用位置和已有原文；保留模型/人工来源与版本 |
| 已否决候选与未否决发现混排 | 误报容易被读作仍需处理的风险 | 未否决发现按严重程度排列；已否决候选单列并明确原始主张的性质 |
| 已保存摘要可能早于后续人工复核或动态验证 | 摘要可能仍宣称“未运行”，与当前证据矛盾 | 使用最新成功的报告摘要；存在后续更新或无法核对关联运行结果时，当前结论取自冻结的结构化记录，历史摘要仍保留在 JSON |
| 覆盖、逆向、动态验证主要输出原始 JSON | 关键缺口和验证结果被配置、日志淹没 | 提取可读的覆盖限制、失败原因、文件处理情况、逆向历史、每轮观察和产物引用；相同输入/异常/输出只展开一次 |
| 旧报告通过 run_artifacts 被加入下一次报告 | 反复导出会让证据清单持续混入历史交付文件 | 导出时排除历史报告产物；任务中的报告历史与幂等重试行为继续保留 |
| 等宽表格、证据说明与代码分离 | 长路径断行过多，位置说明可能留在上一页 | 表格按内容分配列宽；证据说明与代码组成可一起分页的 figure；打印保留重复表头与页码 |

同时补充了运行状态边界检查：一批验证中若混有取消或未知状态，即使该条记录仍保留 result，也不能汇总成“全部完成”。运行范围优先使用已保存结果的 target_scope。

验证覆盖：

- 12 项报告回归测试：字段完整性、格式一致性、原文换行、围栏冲突、HTML 转义、旧摘要失效、阶段报告、混合验证状态、JSON 完整记录、重复轮次和证据分页结构。
- 3 项服务端集成测试：真实代码证据、人工复核修订、不可变历史、幂等导出和历史产物隔离。
- 修改涉及的库、回归测试和离线样稿工具通过严格 Clippy、rustfmt 检查。
- RowVault 与 TextRelay 两份真实任务的冻结数据通过生产 PDF 渲染器生成样稿，最终分别为 13 页和 10 页。已检查全部 23 页及桌面、390px 窄屏显示，未检出页面外文字、空白页或页面横向溢出。验证记录位于 .data/report-quality/html-qa.json 与 pdf-qa.json。
- RowVault 的 3 条运行记录、8 轮观察，以及 TextRelay 的 1 条运行记录、3 轮观察均保留在 JSON 中；人读版只合并完全相同的输入、异常和输出明细，每轮观察标记和退出状态仍单独展示。

全目标 Clippy 还命中了工作区原有临时测试 _scratch_report_render.rs 中的冗余借用（useless_borrows_in_formatting）；上述严格检查限定在本次修改的库、测试及示例目标。

复现命令（在仓库根目录执行）：

~~~powershell
python scripts/aegis.py cargo test -p aegis-application --locked --test report_quality
python scripts/aegis.py cargo test -p aegis-server --locked --test lifecycle report
python scripts/aegis.py cargo clippy -p aegis-application --locked --lib --test report_quality --example report_preview --no-deps -- -D warnings
python scripts/aegis.py cargo run -p aegis-application --locked --example report_preview -- .data/report-quality/rowvault.json .data/report-quality/rowvault --pdf
~~~

JSON 保持 schema_version=1 及原有字段，仍可用于完整证据追溯。人读报告中的核心产物表、重复观察引用和有明确截断说明的长日志摘录用于改善阅读；原始记录仍保留在 JSON 和证据产物中。报告导出不会重新审计、修改已保存的严重度或把静态证实提升为动态验证。

新模板作用于加载此版代码后新生成的导出文件。既有历史报告保持原始内容，重新导出可得到新结构。
